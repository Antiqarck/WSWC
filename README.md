# WSWC ☢️ We Said We Could
We Said We Could — это кооперативный асимметричный 3D-рогалик от первого лица. Пока весь персонал АЭС ушел на перекур, случайное стечение обстоятельств поставило реактор на грань катастрофы. Группа практикантов должна предотвратить взрыв, используя только собственные рукописные конспекты, рацию и метод проб и ошибок.
# 🎮 Основные механики
 - Асимметричный геймплей: У каждого игрока в руках свой уникальный конспект с корявым почерком, зачеркиваниями и опечатками. Чтобы починить любой узел, нужно объединять информацию из всех тетрадей.
 - Радиопомехи и изоляция: Многоуровневая станция глушит сигнал. Бетонные перекрытия и расстояние искажают голосовой чат и вводят шумы в рацию.
 - Радиационные зоны и мутации: Облучение даёт случайные мутации (баффы и дебаффы) — от фосфорного свечения глаз до инверсии слуха и заикания по радио.
 - Рандомизация и Рогалик: При каждом новом забеге меняются конфигурации комнат, типы поломок и инструкции.

# 🚀 Настройка проекта для разработчиков
 1. Клонирование репозитория
Убедитесь, что у вас установлен Git LFS перед клонированием, чтобы корректно загрузились 3D-модели и аудиофайлы.
```bash
$ git lfs install
$ git clone https://github.com/your-username/we-said-we-could.git
```
 2. Открытие в Unity
    1.  Установите рекомендуемую версию через Unity Hub.
    2.  Добавьте проект из локальной папки.
    3.  При первом запуске дождитесь компиляции шейдеров и импорта ассетов.
   
# 📁 Структура проекта
```Plaintext
Assets/
├── _Project/               # Основной контент игры
│   ├── Art/                # 3D-модели, текстуры, материалы
│   │   ├── Environment/    # Модули станции, трубы, гермодвери
│   │   ├── UI/             # Текстуры тетради, шрифты, иконки
│   │   └── Player/         # Модели рук, предметов
│   ├── Audio/              # Звуки сирен, радиопомех, окружения
│   ├── Prefabs/            # Готовые префабы (Player, Interactables)
│   ├── Scenes/             # Игровые сцены (MainMenu, TestChamber, Station_Level_01)
│   └── Scripts/            # C# скрипты
│       ├── Core/           # Менеджер реактора, GameLoop
│       ├── Networking/     # Синхронизация, лобби, радиочат
│       ├── Player/         # Контроллер, Raycast-взаимодействие
│       ├── Manuals/        # Генератор текстов для конспектов
│       └── Mutations/      # ScriptableObjects мутаций и дебаффов
```
# 👥 Команда разработки
Разработчик А: Сетевой код, архитектура систем, логика реактора, радиопомехи.  
Разработчик Б: Геймплей, UI тетради, левел-дизайн, системы мутаций.  
# 📝 Правила работы с Git
Не закоммичивайте временные папки: Папки Library/, Temp/, Logs/ и UserSettings/ находятся в .gitignore.
Ветвление:  
 *main* — стабильная рабочая версия.  
 *dev* — основная ветка разработки.  
 *feature/feature-name* — отдельная ветка под каждую задачу.
